# MangoIdleIslandProbe 0.1.0

这是为“液态玻璃开启后，完全空闲的模拟灵动岛消失”制作的诊断包，目标 iPhone 13 mini / iOS 16.5 / Dopamine RootHide。它尚未实现常驻显示。

## 安装前恢复准备

确认能用设备密码解锁，并能在 Dopamine 关闭插件注入后重新越狱。
若安装后进入安全模式，卸载包 `com.chenxun.mangoidleislandprobe`，再注销。
若无法操作，快速按音量加、快速按音量减、长按侧边键直到 Apple 标志；重启后用密码解锁，在关闭插件注入的情况下重新越狱并卸载此包。
只删除本探针，不修改 Mango 或系统文件。安装包没有自动杀进程或重启脚本。

## 手机测试步骤

1. 通过 RootHide 包管理器安装本包，然后注销一次（Respring 即可）。保留当前 Mango 液态玻璃、16 Pro Max 模拟和倒置补丁设置，测试中不要切换这些开关。
2. 解锁后尽快回到桌面，无音乐、计时器、导航等活动，保持空闲约 15 秒。
3. 播放音乐，让灵动岛显示，返回桌面等约 20 秒。
4. 结束音乐活动；如果暂停后胶囊仍在，可退出播放器。以你实际看到胶囊消失为准，再停留桌面约 20 秒。
5. 距离注销约 2 分 30 秒后，在 Filza 发送下面的日志，并说明“播放时是否出现、结束后是否消失、测试时是正向还是倒置”。

`/var/mobile/Library/Logs/MangoIdleIslandProbe/Probe.log`

不需要电脑、命令行或编辑 Phase 文件。新 Session 在 SpringBoard 进程启动时开始，延迟 10 秒采样，每 2 秒一次，最多 60 次后自动停止。若操作超时，重新注销再做。
发送日志后可卸载这个诊断包。自动停止后不会持续扫描；再次注销会重新开始。要提前禁用，可在上述目录创建名为 `DISABLED` 的空文件，下一次采样停止；移除文件并注销才会恢复。

## 记录范围与边界

通过 UIApplication / UIWindowScene 的公开窗口列表，检查已在实际二进制出现的 SAUI、SystemAperture、MGLiveBackdropView、_SBGainMapView 等视图以及祖先链。记录类名、进程内对象地址、frame、bounds、hidden、alpha、图层可见性、transform 和窗口方向。

不调用未知私有 selector，不替换任何方法，不改变 frame / hidden / transform，不创建新窗口、不记录通知文字、歌曲名、账号、屏幕截图或认证数据。每次最多 32 窗口、1200 节点、20 层深度及 160 个目标/祖先，后台文件写入最多积压一份快照。日志最大 4 MiB，保留当前和上一份；目录权限 0700，日志 0600。遇到写入失败或上限停止。

如果有 `truncated=1`，说明达到扫描限额；列表内没有目标不证明全局不存在，远程宿主/未被公开窗口列表枚举的视图仍需进一步定位。`TARGET` 与 `ANCESTOR` 是首次发现时的记录角色，祖先行也可能是另一个相关视图。

## 下一步判定

- 空闲时仍有非零尺寸宿主，但被隐藏/透明：继续定位可见性写入点。
- 空闲时宿主尺寸为零：不能只强制 alpha/hidden，需要恢复合理的空闲几何或提供独立空闲底座。
- 只在活动时出现相关视图：考虑由稳定窗口承载专用空闲底座，并与活动状态交接；不得冒充真实活动或覆盖交互。
- 扫描截断/没有窗口：先补充运行时观察，不据此生成写死地址的修复。

源码和包检查通过不能代替真机稳定性与显示验证。此包是诊断步骤，常驻显示补丁尚未完成。
