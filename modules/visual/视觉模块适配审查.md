# Beta9 视觉模块适配审计

目标为 Mango `1.0-Beta9-1`、MangoSuite `1.2.0~beta9.5`，沿用 iPhone 13 mini / iOS 16.5 / Dopamine RootHide / arm64e 的验证范围。本报告只记已读取的二进制证据；真机效果另行验收。

## Idle 原生玻璃接口

Beta9 仍在 `MangoPanda.dylib` 和 `MangoHello.dylib` 中定义 `MGLiveBackdropView`。以下接口在两个镜像中的完整 Objective-C 类型均与 Beta8 相同：

| 方法 | 类型 |
| --- | --- |
| `initWithFrame:groupName:filterType:` | `@64@0:8{CGRect={CGPoint=dd}{CGSize=dd}}16@48@56` |
| `lgFilterType` / `lgSpecularEnabledOverride` | `@16@0:8` |
| `setLgSpecularEnabledOverride:` | `v24@0:8@16` |
| `reapplyFilterForParameterReload` / `updateSpecular` | `v16@0:8` |

实现地址随版本变化，见相邻 `visual-audit.json`。现有 Idle 按实际对象的类和镜像验证原生玻璃，构造前核对 CGRect/group/filter 完整 ABI；这些限制仍适用。保留原生 Island filter、紧凑几何、presentation 透明度、可见活动交接、偏好缓存及主队列重载逻辑即可，不需要新增视觉替代机制。系统 UIKit 继承的方法继续由运行时签名检查保护。

## AdaptiveColor 精确保留

保留 inputs 中 SHA256 `840d1d77b7d6b10a6c2959371e1abc367041ef343ba9e393c831186f39b5ba5c` 的 AdaptiveColor `0.1.3` dylib 和参数 UI。原件的四个 shader 匹配点（flat tint、curved tint、dispersion、glare）在 Beta9 原始 shader 中各出现且只出现一次；原入口和 helper 插入点也是唯一。替换完整使用该原件的 CFString 常量，未用旧仓库的不同源码覆盖功能。

**Beta8 与 Beta9 原二进制内的 shader 字符串逐字节相同**，均为 18516 字节，SHA256 `448af1dc55fdb679c49ff600576b3073e5f5b3043d2db6727b670612dd093250`。旧 `Beta8-original-shader.metal` 是本地 CRLF 文件，不能用其文件 hash 判断 shader 改变。新 exact rewrite 按真实二进制的 LF 换行保存，23939 字节，SHA256 `37f427cbaf267d4021f7fc99086f666ef7a1261f64c7a0a9cd78a21342b93a95`；与旧重建 shader 归一换行后相同。新文件只作为本地私有 Metal 编译输入，完整 shader 不进入公开源码或交付包。

本轮选择针对此 LF hash 重新实际调用 Apple Metal 编译器。当前审计完成时编译证据待本次 CI 产生；不要把旧 CRLF hash 的编译报告当作新文件 hash 的证明。加载器仍须在 MangoOSRendering 初始化构建 shader 前装载 Adaptive hook。

## 参数与重载链

Beta9 MangoOSRendering UUID 为 `7D067B62-6203-3D64-BE8A-3A4A7E965959`，镜像 SHA256 为 `24b868f364ff33b398daf866b8b2113e90870954160fd755ab90aa1522cd872c`。与 Beta8 对照，其全部文件承载 section 相同（包括 `__text`、`__cstring`、group 默认表与 CFString）；镜像整体身份已变化，加载器需使用 Beta9 身份。

Island 默认表仍在 `0x14ba8`，stride `0x50`。`+0x28` float 为约 `0.1`（Blur）；`+0x2c` float 为 `5`（DispersionStrength），Light/Dark RGBA 仍为全零。未保存 DispersionEnabled 时继续按默认 strength > 0 判断开启；缺失 Global.DispersionStrength 不覆盖 group 默认值。

边缘光 opacity 默认仍为 `0.6`：Beta9 Panda 的 `updateSpecular` 在 `0x804fe8` 从 `0xa06760` 读取此 double；同版可读的 MangoOSPrefs 在 `0x57b00` / `0x57c08` 从 `0x69418` 读取此 fallback，继续读取 group `.SpecularOpacity` 并约束至 0–1。整合页 `Island.SpecularEnabled` 缺省关闭是保留的用户主动开启策略，不代表 Mango 原生全局缺省关闭。

偏好 domain、键、通知顺序均不变：`0x6494` 注册 `com.go.mangoosprefs/Reload` 回调 `0x88fc` → `0x8934` 调用缓存重载 `0x7d00` → `0x7d54` 以 CurrentUser / AnyHost 读取 CFPreferencesCopyMultiple → `0x89ec` 后发布 `go.mangoos/ParametersReloaded`。GlassPage 继续发送前一通知，让原版先读缓存再发送后一通知。基础色调 UI 分别保留 Light/Dark RGB，写 alpha 后清除 scalar `Island.TintStrength` 的现有逻辑仍适用。

## 结论与验收范围

视觉适配需要刷新 Beta9 镜像身份与版本元数据，保留现有 ABI 检查、Idle 行为、Adaptive 原件和玻璃参数页面。ABI、默认值、重载路径和 shader 匹配审计通过；编译与 host harness 结果由本轮构建报告记录。静态与编译证据不能证明真实媒体标题/封面可见、边缘光外观或动画时序；本轮尚未连接设备做这些验证。
