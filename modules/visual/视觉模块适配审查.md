# Beta8 视觉模块适配

目标设备：iPhone 13 mini / iOS 16.5 / Dopamine RootHide。基准为 Mango 原版 1.0-Beta8-1，以及 MangoSuite inputs 中精确的 IdleIsland 1.1.9.2~alpha2 和 AdaptiveColor 0.1.3。

## 已确认差异与改动

IdleIsland 原代码将 MGLiveBackdropView 所属镜像限制为 mango.dylib / mangoos.dylib。Beta8 已拆为 MangoPanda.dylib / MangoHello.dylib，因此旧版会无法识别原生玻璃并退回 UIKit。

新源码目录 `MangoIdleIsland`，版本 1.1.9.3~beta8.1：

- 镜像限制更新为精确的 Panda / Hello 名称，并验证实际对象所属类；不扩大到任意第三方玻璃类。
- 两个 Beta8 镜像的 initializer / filter / override / reapply 方法已从 Mach-O Objective-C 元数据核对，完整类型相同。构造时新增 CGRect / group / filter 全参数编码校验。
- PillGlass.Enabled 改用 CFPreferences 获取，避免猜 RootHide plist 路径。
- 边缘光偏好每秒至多同步一次，原始实现会在 30 fps 扫描过程中重复同步偏好。收到 Mango 重载通知立即失效缓存。
- Darwin 回调在主队列更新 generation 和操作所有视图，快速重载只执行最后一轮。
- 移除 SpecularProbe 第二套诊断 hook、ProbeIvar 代码以及 specular setter 每次文件日志。保留现有会话、状态变化和纠正失败时的有限日志。
- 不编译旧 TintMigration：它仅处理 1.0.0 写入的旧 scalar 遗留问题，不是 Beta8 适配必需。新模块不会在启动时修改原 Mango 的偏好。
- 保留 alpha2 的紧凑尺寸限制、presentation 透明度、presentation 尺寸限制、逆透明度交接。没有添加未经设备证据支持的新视觉效果。

## 自适应颜色保留精确原件

实际 inputs 中 AdaptiveColor 0.1.3 是带独立参数 UI 与颜色标记编码的版本；旧 repo 中同版本 Tweak.m 并非这一交付二进制对应源码。不能以旧源码重编后覆盖，否则会丢失已交付的参数功能。

保留该精确 dylib 与 PreferenceBundle；其四项 shader 匹配点在 Beta8 原始 Metal 源码中各恰好出现一次：

1. flat tint mix。
2. curved tint mix（增加 Island 高亮边缘处理）。
3. dispersion 强度（仅 Island marker 改变）。
4. glare 输出（仅 Island marker 改变）。

原模块还要求唯一的 mangoGlassPixel 入口与 Uniforms 结构，生成 helper 的全部标量、曲线和标记校验均保持原件。最终源码已由原 dylib 的 CFString 常量重建为 `Beta8-adaptive-exact-rewrite.metal`，没有使用猜测的 shader 替换。

Beta8 Rendering 保持 CFPreferencesCopyMultiple / com.go.mangoosprefs / 当前用户、AnyHost 读取方式。在 loader 中提前加载原 AdaptiveColor，保证 Mango 创建 shader 前安装 hook。

## 原版参数默认值与通知链

MangoOSRendering UUID：`0D23BE7C-63FC-335E-A5B2-6773627BA077`。

默认结构表 Island 位于 0x14ba8，stride 0x50。`Island.Blur` 偏移 +0x28 = 0.1；`.DispersionStrength` +0x2c = 5。0x82e4 / 0x815c 的写入明确验证上述映射。Light/Dark RGBA 全零。未存 DispersionEnabled 时由默认 strength > 0 判断，故 Island 默认开启。缺失 Global.DispersionStrength 不覆盖 group 默认值。

`Island.SpecularOpacity` 运行时默认 0.6：Panda updateSpecular 入口 0x7c03f8/0x7c03fc 从 0x9aaf20 读取 double 0.6；同版设置内可读的 updateSpecular 从 0x69148 读取同值，然后读取 group 的 .SpecularOpacity 覆盖并约束到 0–1。工具的 SpecularEnabled 缺省关闭是显式 opt-in 策略，不能混称为 Mango 原版全局缺省关闭。

通知链完整保留：0x6494 注册 com.go.mangoosprefs/Reload 回调 0x88fc → 0x8934 调用 0x7d00 → 0x7d54 读取 CFPreferencesCopyMultiple → 更新缓存 → 0x89ec 发布 go.mangoos/ParametersReloaded。GlassPage 应发前一通知，让原版自行读取后发后一通知。

## 必需构建与有意义验证

源码编译：在 Theos RootHide 工具链执行 `make -C modules/visual/MangoIdleIsland package FINALPACKAGE=1`（THEOS 环境沿用整合框架 CI）。

实际 helper 测试：`python3 modules/visual/tests/test_idle_handoff.py --require-clang`。它在 macOS 编译执行当前源码的三个 helper 与当前 Update 数学表达式，覆盖 presentation 淡出、祖先透明度、紧凑返场、展开/长按排除、NaN/Infinity。额外的双算透明度与只看 model 尺寸两个负对照必须失败，证明测试确实能抓住原有回归。这些 property stubs 不模拟 UIKit 的真实动画时序。

Metal 编译：`xcrun -sdk iphoneos metal -c modules/visual/Beta8-adaptive-exact-rewrite.metal -o build-info/Beta8Adaptive.air`。该文件为完整 shader，自带 metal_stdlib，无需测试 harness；可选 `xcrun -sdk iphoneos metallib build-info/Beta8Adaptive.air -o build-info/Beta8Adaptive.metallib`。

本地已完成：两份 runtime method ABI、原件四项替换、默认表和源码范围检查。macOS CI [36913456075](https://github.com/Zeimochenxun/MangoUpsideDownProbe/actions/runs/36913456075) 已实际编译本轮 arm64e Idle、执行 helper 与两个负对照，并用 Apple Metal 编译精确最终 shader（SHA256 `af6430f9d38830c81fd924f7fee8b1851535af7e26f23336023253b241f46259`，AIR 27312 字节）。最终原 Adaptive 模块与 UI 精确一致，7 个成品镜像代码页签名全部通过。仍不能据此宣称真机全部视觉场景已验证。
