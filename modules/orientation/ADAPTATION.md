# Beta9.6 方向模块状态

目标 Mango 1.0-Beta9-1、iOS 16.5、Dopamine RootHide、arm64e。Hello／Panda／Rendering 身份校验和原生倒置独立存储保持原有策略。

本版默认崩溃隔离，World／WorldPlacement／XiaoMang、Split 及其它整合模块不加载，因此方向补偿和资源库修复不生效。原有设置保留，Mango 原版自行处理方向和通知。没有改原始二进制或授权。

包内保留 Beta9.5 的方向模块代码以支持明确关闭隔离的选择；用户已确认该版通知上滑仍会进入安全模式，关闭隔离不构成解决办法。其手势观察器原样调用原入口，已无位移／速度改写，资源库观察不写坐标，但几何和布局路径仍不能排除。

新增 Foundation 启动观察器记录当前镜像 UUID、计划与实际加载。需真实 SpringBoard 崩溃报告和隔离结果进一步定位，不能将构建通过或矩阵正确当成真机稳定证据。
