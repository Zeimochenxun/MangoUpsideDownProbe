# 小芒同学 Beta8 倒置适配

版本：`1.1.0~beta8.4.1`（Diagnostics）。完整安装包：`MangoSuite-1.1.0-Beta8.4.1-Diagnostics-RootHide-arm64e.deb`。目标是 iPhone 13 mini、iOS 16.5、Dopamine RootHide，以及已经正常授权的 Mango `1.0-Beta8-1`。

当前状态：保留 Beta8.2 的小芒几何和动画实现，沿用 Beta8.4 的共享方向策略。Beta8.4.1 仅增加有限只读日志与 collector，不新增小芒修复行为。**新诊断包尚未在手机验证，本轮也没有小芒专项通过证据。** 用户已有 Beta8.4 完整用户空间重启后的媒体／启动器问题反馈；这些反馈及原生倒置偏好工具此前生效的结果，不能代替小芒窗口的显示和交互验收。

## 范围与开关

适配编入现有 `MangoUpsideDownWorld` 模块，使用“设置 → Mango 整合 → 倒置方向与小芒修复”开关。没有新增动态模块、设置入口或单独的小芒开关；关闭整合总开关或该修复开关并重新启动用户空间，会同时停用对应的系统灵动岛和小芒修复。

| 小芒界面 | 适配范围 |
|---|---|
| 悬浮球 | 260×260 主窗口的倒置方向与位置、布局更新和方向复位 |
| 根面板 | 随主窗口转向的内容和按钮，保留原生面板布局及滚动／手势空间 |
| 独立通知泡与展开卡片 | 每个通知独立窗口的方向、位置及几何更新；不把它们误当作主窗口内的子视图 |
| 同类提示窗 | 使用相同 `XMFloatingWindow` / `XMPortraitVC` 组合的原生提示窗口 |

“Mango 原生屏幕倒置”仍是独立的 Mango 偏好。关闭整合修复不会清掉已保存的原生倒置值；首次安装不会擅自改变该值。原版 Mango 倒置设置页会清回关闭，测试时请从整合设置页控制。Mango 的原生功能是否可用仍由其正常授权与设置决定，本适配不修改 Mango 二进制或授权逻辑。

## 实现边界

只给经 Beta8 Panda UUID、类来源和已确认方法 ABI 校验的原生小芒窗口添加几何处理。原生 root controller 保持 portrait 的局部布局模型；本插件将整个窗口围绕物理屏幕中心半转并同时修正位置，而非只翻转内容。

窗口父坐标与物理屏幕坐标可能不同。`XiaoMangGeometry.h` 从实际三点映射推导需要的父坐标位移；应用后再次检查三点是否等于物理屏幕镜像。已有原生倒置的实际 basis 不再增加半转，不支持的几何会跳过或恢复本插件拥有的值。

几何 setter 使用每个窗口自己的嵌套计数：原生布局在本插件拥有的变换暂时恢复后执行，外层完成时重算。仅当当前 transform 仍匹配本插件记录时恢复，避免把陌生变换清成旧基线。World 的应急停用标记同样覆盖小芒，兼容原路径和 RootHide 映射路径。

不另行改写球、面板和通知的手势位移，也不替换原生 `hitTest:withEvent:`。已核对的拖动入口使用窗口／父视图／接收视图的局部坐标；半转后的 UIKit 坐标映射负责方向转换。原始窗口 hit-test 对空白根视图透传，真正子控件继续处理点击。

倒置补偿时，外层窗口的恢复、原生几何变更和重新半转在禁用窗口几何动画的事务中完成，直接落到最终镜像位置。这样避免临时原生 baseline 到 π 的旋转，以及原生逻辑 frame 动画与镜像位移端点不一致。已有原生倒置或其他方向不采用这一补偿事务；独立子视图和透明度动画继续保留，不能承诺所有原生窗口位置动画完全不变。

首次施加半转、镜像几何事务及恢复本插件拥有的变换时，仅清理外层 layer 已挂的 `position`、`bounds`、`transform` 属性动画（包括子属性）及纯几何动画组。透明度、混合动画组和全部子层动画保持，避免一并删除通知 fly-in 或其他独立效果。此策略已经落实到源码；动画连续性、方向切换时序和实际显示仍待真机验收。

## 最少真机检查

Beta8.4 已完整用户空间重启后的反馈为岛还在但没有媒体内容、分屏启动器偶发回正，桌面与锁屏仍倒置。现有 shell World 日志是当前会话，rootfs World 副本是旧历史；Idle 原生 element/glass 交接存在，但不能证明标题、封面像素可见，归档也没有故障复现标记。这些记录没有确认小芒几何或动画是根因。

诊断版三个模块的新会话最多记录 20 分钟，新日志每模块约 256 KiB，只读观察既有决策和视图几何、透明度、裁剪；collector 立即保存限定日志，不改变小芒窗口行为，不读取媒体标题、封面数据或授权。针对已报告媒体与分屏现象的采集顺序见 [运行时诊断说明](../../diagnostics/RUNTIME.md)。本版不要求重复未改变且已有通过证据的场景；下列小芒项目保持原验收边界。

完整包安装后重新启动用户空间，启用原生倒置与“倒置方向与小芒修复”。以下项目均待测试：

1. 球在屏幕各边缘正向→倒置→正向，检查位置、方向及复位后无累积偏移。
2. 倒置时拖球，展开面板、点一次按钮并收起，检查拖动方向、命中位置和面板状态。
3. 显示独立通知，点击展开卡片、拖动通知泡并关闭或等待消失，检查内容、位置和窗口释放。
4. 点击球、面板和通知窗的透明空白处，检查下层应用仍收到原有透传触摸。
5. 保留已有窗口来回旋转，再在倒置后产生新通知或打开同类提示窗，检查已有与新窗口，以及横屏→倒置→正向后的恢复。

只对失败场景增加复现和针对性检查，不重复未改变且已经通过的项目。异常请记录方向、当前开关、具体动作和是否重启用户空间，并查看 `[MangoSuiteXiaoMang]` 系统日志；不需要导出授权数据。
