# IdleIsland 通知清除恢复修复 alpha2

用户在 `1.1.9.1~alpha1` 上反馈：通知上划清除后，常态灵动岛暂时消失，稍等会恢复。本版更新 IdleIsland 为 `1.1.9.2~alpha2`。

alpha1 对常态模型尺寸与 presentation 尺寸增加了宽高差不超过 0.5 点的要求。模型 125×36.67、显示 129×38 或 125.8×36.67 都在常态尺寸范围内，但它仍将常态玻璃移除，形成可复现的空档。

alpha2 保留模型与 presentation 都必须处于原常态尺寸区间的检查，删除 0.5 点一致限制。通知收拢进入常态尺寸范围后可以恢复玻璃；150×44 等展开尺寸继续拒绝。透明度算法、内容 fallback、可见性检查、hook 和计时器保持 alpha1 行为。

状态切换日志补充 presentation 尺寸、内容/玻璃各自透明度、常态玻璃实际挂载与 hidden 状态，便于区分尺寸门限与活动层残留。日志位置仍为设备上的 `/var/mobile/Library/Logs/MangoIdleIsland/Status.log`。

## 使用

只替换 IdleIsland 为本版即可。AdaptiveColor 保持当前版本；GitHub 中同时提供上一轮已编译检查过的 `0.1.3.3~alpha1`，内容未改。

安装后重新启动用户空间，再测试通知出现→上划清除→常态恢复，以及长按展开→松手回弹、音乐活动切换。原版 IdleIsland 1.1.9 位于 `rollback/`，如出现异常，使用原安装器允许降级安装并重新启动用户空间。

常态范围是宽 110–145 点、高 28–45 点。本版会比 alpha1 更早显示回弹的紧凑尾段，仍需真机核对尾段位置和双层表现。

尚未取得本次通知退出的设备日志，因此这里只修复已在代码中证实的门限空档；如果上划活动层已离开岛体、但 presentation 透明度仍为 1，仍可能存在另一条延迟分支。不能把 CI 通过等同于本次真机问题已确认消除。
