# Mango Suite Beta9.3 测试版

版本 `1.2.0~beta9.3`，安装包 `MangoSuite-1.2.0-Beta9.3-RootHide-arm64e.deb`。
适用于已正常运行的 Mango **1.0-Beta9-1 / iOS 16.5 / Dopamine RootHide / arm64e**，沿用现有 iPhone 13 mini 目标。

Beta9.3 专门处理上版启动器仍无法倒置的反馈。日志显示方向2已识别，但窗口旋转后的校验坐标仍为正向，随后修正长期暂停。本版在“启动器重开倒置恢复”开启时改为修正已验证 Mango 启动器的内容根视图，使用子层坐标校验，并为其保存独立所有权；停用或返回正向时恢复自身变换。

## 安装和使用

覆盖安装完整 MangoSuite 包，然后在多巴胺中重新启动用户空间。
进入 **设置 → Mango 整合 → 本版问题修复**。已有开关和原生倒置偏好保留；不会重写 Mango 原版模块。
七项新开关分别保存，默认开启六项修复；边缘采色默认关闭。新开关和采色参数在模块加载后约0.5秒内刷新。
总开关、原来的四个模块开关仍需要重启用户空间；原生倒置仍按原来的保存及 Respring 流程应用。
“启动器重开恢复”依赖分屏模块，“调整大小保持倒置”和“通知上下滑方向”依赖倒置方向模块。关闭对应旧模块后，这些新修复不会单独加载它。

| 独立开关 | 本版实现 |
|---|---|
| 1 椭圆轮廓与四角修复 | 统一投影后的圆角轮廓，限制退化半径；用一个轮廓绘制边缘，关闭对应原生 specular，避免两侧重复描边 |
| 2 启动器重开倒置恢复 | 通过启动器内容根视图和子层坐标修正，避免窗口坐标未响应导致长期暂停；处理 Dock／资源库重开后的变换重置与原生场景映射变化 |
| 3 液态玻璃过渡动画修复 | 读取当前 presentation 几何，连续更新同一轮廓；保留 Mango 玻璃内容，避免分别缩放左右端帽 |
| 4 调整位置大小保持倒置 | 根视图／内容布局时保持已确认的倒置坐标空间；新的有效几何可恢复先前被暂停的修正 |
| 5 短通知黑色光晕修复 | 针对 Mango 通知提供视图，建立显式阴影路径和最低模糊半径，在父层绘制，避免内容高度和自身裁剪影响 |
| 6 灵动岛边缘实时采色 | 四方向环外采样，按颜色面积和饱和度选择色调；平滑更新光学渐变，不保存截图 |
| 7 通知上下滑动方向修复 | 在已验证且确实倒置的灵动岛通知坐标内，对通知结束手势的纵向位移和速度查询补偿，覆盖 Aperture 和 MangoPill 两个入口 |

粗细可调 **0.5～4点**，动态程度 **0～1**。动态程度影响颜色响应、采样频率、亮度及细微高光游动。采样通常为每秒4～8次；捕获单次超过20毫秒时降到每秒2次。静止且未开启采色时暂停逐帧刷新，过渡几何最多30帧／秒；分屏揭示恢复最多60帧／秒、持续1.2秒。
采色优先使用运行时存在的系统屏幕图像接口；不能使用时尝试 SpringBoard 背景窗口，日志区分 `display-pixels` 和 `springboard-window-pixels`。后者不能保证包含前台 App 的全部画面。采集失败时移除采色效果或使用已启用的普通白色边缘，不用虚构颜色代替。需要真机确认该设备支持哪条采色路径。

## 一键日志

进入 **设置 → Mango 整合 → 调试日志与一键提取**：

1. 点击 **开始／重新开始记录**。
2. 复现异常；每个记录会话持续20分钟，每模块最多256KB。
3. 回到页面，点击提取全部日志，或按玻璃／光晕／采色、分屏启动器、倒置与手势分别提取。
4. 在系统分享页面保存或发送生成的 `.txt` 文件。

默认不记录。记录只包含时间、会话、尺寸、方向、动画几何、采色可用状态和修复开关，不保存通知文字、封面或截图。重启／重新记录后请以日志里的会话号区分。旧的 shell 提取工具仍包含在包中。

一键提取只保留当前记录会话。启动器日志新增 `correctionTarget=launcher-content-root`、`rootModel`、`rootBasis`、`rootEligible`。请安装后重新点击“开始／重新开始记录”，再复现并提取启动器与分屏日志。

## 验证范围

本版新增针对原生场景重复半转的可执行回归、七项独立偏好和采色数学验证；实际构建与包校验结果以交付目录中的 `build-validation.json` 和 `package-verification.json` 为准。
没有连接手机，不能将这些结果视为七项问题的真机验收。请按照 [真机验收](ACCEPTANCE.md) 使用你提供的具体复现路径检查。
AdaptiveColor 0.1.3 原模块及 shader 输入没有修改，本次复用相同输入的既有 Apple Metal 编译证据；发生变化的 Objective-C 模块在本次重新构建。

## 停用和回退

关闭相应新开关即可移除本版补充绘制或恢复此前策略。关闭整合总开关并重启用户空间可停用所有整合模块。
原生倒置开关独立保存；若要恢复正向，请单独关闭它并按原流程应用。
交付目录包含上一版 Beta9.2 完整包作为回退包。重新安装并重启用户空间后恢复上一版代码，偏好设置保留。
