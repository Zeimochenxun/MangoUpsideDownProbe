# Mango 整合补丁 Beta8

版本：`1.1.0~beta8.1`。完整安装包：`MangoSuite-1.1.0-Beta8-RootHide-arm64e.deb`。

一个安装包、一个“设置 → Mango 整合”入口，提供原生屏幕倒置开关及四项整合修复。需要已经正常授权的 **Mango 1.0-Beta8-1**；不包含 Mango 主插件。

本版适配目标为 **iPhone 13 mini、iOS 16.5、多巴胺隐根（Dopamine RootHide）、arm64e**。加载器核对 Beta8 原版模块身份，版本或模块不匹配时不强行挂钩。普通 rootless/rootful、其他 Mango 版本及其他系统版本不在此次验证范围内。

## 安装与使用

1. 使用 Sileo 等安装完整 `MangoSuite-1.1.0-Beta8-RootHide-arm64e.deb`。可覆盖旧 MangoSuite；包管理器会替换旧独立修复包和之前的独立倒置偏好工具。确认安装操作保留 **Mango 主插件**，不要安装构建用的 helper 中间包。
2. 安装完成后，在多巴胺中执行一次 **重新启动用户空间**。
3. 打开 **设置 → Mango 整合**，按需调整开关和两类参数。

| 设置 | 作用 | 更改后如何应用 |
|---|---|---|
| 启用整合修复 | 管理下方四个修复模块，保留各项选择 | 重新启动用户空间 |
| 静止灵动岛与过渡修复 | 静止时补充原生玻璃，维护紧凑活动与静止状态的过渡 | 重新启动用户空间 |
| 背景颜色自适应 | 使用原 AdaptiveColor 参数与渲染机制 | 重新启动用户空间 |
| Mango 原生屏幕倒置 | 保存 Mango 原生倒置偏好 | 完整关闭设置再打开检查保存，然后 Respring |
| 倒置方向修复 | 修复系统灵动岛倒置时的位置、方向与手势 | 重新启动用户空间 |
| 分屏倒置修复 | 修复 Mango 分屏窗口的倒置方向与拖动 | 重新启动用户空间 |

**“Mango 原生屏幕倒置”独立于“启用整合修复”。** 关闭整合总开关不会关闭已经保存的原生倒置。首次安装不会擅自开启或关闭该原生偏好；之前独立工具保存的值继续由 Mango 使用。

**测试期间不要进入 Mango 原版的倒置设置页，它会将倒置偏好清回关闭。** 需要检查或更改时使用整合页面中的原生开关。

总开关和四个修复开关在进程启动时决定模块是否加载。更改这些开关后，仅 Respring 无法重新加载 backboardd 中的自适应渲染模块，请重新启动用户空间。原生倒置开关单独更改时按表内步骤操作。

## 玻璃与颜色参数

“玻璃与边缘光参数”影响 Mango 灵动岛的静止与活动状态；“自适应颜色参数”保留精确 AdaptiveColor 0.1.3 的参数页面。

自适应启用时，基础色调强度不可调，请在自适应参数页调整明暗不透明度。关闭自适应并重新启动用户空间后，基础色调强度恢复可调，并分别保留浅色、深色 RGB。光斑强度属于 Mango 全局设置，也会影响其他开启光斑的玻璃区域。

本版根据 Beta8 的实际运行代码修正面板缺省值：色调通透 `0.1`、边缘光强度 `0.6`、光斑强度 `5`；已保存的参数优先，不会被这些缺省值覆盖。边缘光继续采用用户主动开启的策略。

## 本次适配内容

- **加载器、Idle、World、Split、统一设置页重新编译。** 更新 Beta8 模块身份与方法校验，原 Mango 文件与授权检查保持原有机制。
- Idle 识别 Beta8 的 MangoPanda/MangoHello 原生玻璃，保留紧凑尺寸与 presentation 透明度交接；缓存偏好、合并重载，减少重复读取和诊断日志。
- World 与 Split 针对 Beta8 重建方向、放置与手势修复，维持各自的系统窗口／分屏窗口作用范围。
- **AdaptiveColor 的运行二进制及参数 UI 保留精确 0.1.3 原件。** 对照 Beta8 原 shader 验证其四项替换，保留已有颜色与高亮机制；没有使用不对应的旧源码覆盖这些功能。
- 整合修复配置继续使用统一的 RootHide 存储与原子保存，兼容有效的旧设置，修改一项保留其他项及未知键。损坏、不可读或保存失败时报告错误并保留原值。原生倒置则单独写入 Mango 偏好域，并同步、回读校验。
- 独立模块不再各自注入或显示独立首页；保留一个简洁设置入口。

## 停用与恢复

只停用四项修复：关闭“启用整合修复”，再重新启动用户空间。原生倒置保持原来的选择。

恢复正向：单独关闭“Mango 原生屏幕倒置”，检查保存，再 Respring。需要卸载整合包时，可先按需要调整原生开关，再卸载并重新启动用户空间；已保存的 Mango 参数不会由卸载操作主动清空。不要为 Beta8 装回针对旧 Mango 版本的独立方向修复包。

## 构建说明

macOS CI 使用 RootHide Theos、固定校验的 iOS 16.5 SDK 与 arm64e 工具链，构建加载器、Idle、World、Split 和统一设置页。原 AdaptiveColor 二进制及 UI 在本地组包时加入；Mango 原版二进制与完整 shader 不进入公开构建仓库。

`helper` 为构建中间产物，不能代替完整安装包。请仅向设备安装交付的 `MangoSuite-1.1.0-Beta8-RootHide-arm64e.deb`。
