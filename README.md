# Mango Suite Beta9.5 回归缓解版

Suite 版本 `1.2.0~beta9.5`，适用于 Mango **1.0-Beta9-1 / iOS 16.5 / Dopamine RootHide / arm64e**。

用户已确认 Beta9.4 回归：左侧滑动动画位置异常，右侧蜂巢资源库反向，通知上滑后进入安全模式。本版先撤下相关新增改写并补充观察日志，不表示七项原始问题已经修复。尚未收到这次 SpringBoard 崩溃报告，也未连接手机验收。

## 安装

覆盖安装完整的 `MangoSuite-1.2.0-Beta9.5-RootHide-arm64e.deb`，随后在多巴胺中重新启动用户空间，使旧的手势和布局挂钩退出进程。只覆盖安装而不重启不能撤掉上一版已经加载的处理。

设置入口：**设置 → Mango 整合**。总开关、原模块开关、七项选择和原生倒置偏好保留。原始 Mango 文件和 AdaptiveColor 没有修改。

## 本版变化与剩余问题

| 项目 | 当前状态 |
|---|---|
| 启动器、左右资源库、底部设置 | 撤下 Beta9.4 对子容器和菜单呈现层的独立半转及四个布局挂钩，恢复 Beta9.3 启动器根视图策略。该策略只有历史部分改善，左侧动画位置、右侧蜂巢和底部设置仍待验收与后续修复 |
| 通知上下滑最终动作 | 停用纵向位移和速度查询改写，通知动作由 Mango 原版处理。第7项显示“暂停”并不可操作，保存值保留但不会启用方向补偿；最终动作反向的问题仍未解决 |
| 玻璃边缘和过渡 | 不再替换原生玻璃裁剪层；保留每层独立的补充描边、轮廓和采色。通知状态观察延后到原回调返回后合并处理，减少收起时的同步介入。四角、错位及动画仍待验收 |
| 位置与大小调整 | 撤下 Beta9.4 新增的窗口缩放终点替换和位置模块两秒方向桥接，恢复 Beta9.3 策略；调整过程保持倒置仍待验收 |
| 短通知光晕 | 保留实际通知提供者识别和窗口层阴影。短高度下是否稳定可见仍待验收 |
| 边缘实时采色 | 保留四方向采样、面积和饱和度选色、平滑过渡；粗细0.5～4点，动态程度0～1。前台 App 采色能力依设备实际接口，日志区分屏幕像素与 SpringBoard 背景窗口 |

各开关仍独立保存，边缘采色默认关闭。除暂停的第7项外，新开关和采色参数约0.5秒内刷新。总开关和原模块开关依旧需要重启用户空间；原生倒置按原保存流程应用。

## 日志

进入 **调试日志与一键提取 → 开始／重新开始记录**，记录20分钟，每模块最多256KB。复现后提取全部相关日志并保存 `.txt`。

- `SURFACE observer=1 writes=0 hooks=0` 区分左右启动器、普通资源库、`watchPickerView/Right` 蜂巢资源库和底部设置；记录原始变换、位置、裁剪与呈现动画位置。只读观察器不调整这些视图。
- `PAN install query=0 correction=paused` 说明补偿已停用。`PAN native-begin/native-return` 用同一序号记录原手势入口及是否返回，不读取通知文字，不修改识别器的位移或速度。
- `Glass clipOwned=0` 说明未替换原生裁剪层；光晕、轮廓和采色状态继续记录。

若仍进入安全模式，先导出已有会话，不要先点击重新开始记录；再附上对应时间的 SpringBoard `.ips` 或 `.crash` 报告。仅凭进入安全模式和调试日志不能确定崩溃调用栈。

## 验证和回退

构建与包证据见 `build-validation.json` 和 `package-verification.json`。本版执行生产手势观察器的动作阈值、识别器不变、异常传播、嵌套和日志失败回归，源码边界检查带移除路径的负对照，并重新编译 iOS 16.5 arm64e 代码。这些检查不能证明手机稳定、位置正确或绘制已修复。

完整压缩包附 Beta9.3 回退包。它是较早的部分改善版本，仍有已知问题；重新安装后重启用户空间，偏好保留。Beta9.4 不作为推荐回退版本。关闭整合总开关后重启用户空间可停用整合模块；原生倒置开关独立保存。

进一步检查见 [真机验收](ACCEPTANCE.md) 和 [诊断说明](diagnostics/RUNTIME.md)。
